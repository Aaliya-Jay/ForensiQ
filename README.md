## 🌟 Overview
ForensiQ is not a traditional AutoML pipeline. It is an **autonomous data scientist agent** that:
1. **Investigates** raw, unseen CSVs for anomalies (missing data, imbalance, high cardinality, duplicates).
2. **Plans** tailored remediation strategies using LLM reasoning.
3. **Acts** via deterministic Python ML tools.
4. **Observes** model metrics.
5. **Reflects** on underperformance.
6. **Autonomously Corrects** and retries to optimize results.
